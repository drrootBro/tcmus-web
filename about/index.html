关于我们：核验方法论

一句话结论：三步——查执照（州政府公开可查）、问医师（免费挂牌换执照号）、听患者（问诊三问 + 四项评价）。方法论全公开，欢迎来挑刺。

第一步：查执照

美国没有"中医师"执照，只有各州的针灸师执照（纽约叫 L.Ac.）。我们去州教育部门/针灸委员会官网，按医师姓名公开查询。

每家店标注三种状态：

  • ✅ 执照已核验：查到有效执照
  • ⏳ 待核验：信息收集中
  • ❌ 查无此人：公开渠道查不到，如实标注

第二步：问医师（免费挂牌）

我们主动联系老板，免费做黄页页面，换三样东西：医师姓名 + 执照号 + 确认过的地址电话。

为什么这么干？我们发现公开数据会烂：有家店官网显示搬去长岛了，谷歌上还是老地址；有家店官网地址和谷歌地址对不上。老板自己给的信息，最新最准——这是送，不是求：免费曝光换准确信息，双赢。

第三步：听患者（四项评价）

患者没专业知识，判不了"辨证准不准"——所以我们只问患者能感知的：

  1. 认真负责（排第一）
  2. 问诊几分钟？（1 分钟以下 / 1–5 分钟 / 5 分钟以上）
  3. 告没告诉你为什么选这些穴位？
  4. 上来就扎满走流程，还是从容不迫？
  5. 针感描述（只记录，不评判）：麻 / 触电 / 酸胀 / 没感觉——得气好坏有流派争议，站长不站队
  6. 价格透明度：事前报价 vs 事后加价
  7. 过度推销：有没有捆绑疗程、卖药压力

我们不做什么

  • 不收上榜费：黄页免费挂牌，严选靠亲历——宁可空着，不凑数
  • 不删差评：只删人身攻击和不实指控
  • 不编数据：没核验的就是"待核验"，不写"大概""可能有"
